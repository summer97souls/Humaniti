# Humaniti

**Live:** https://humaniti-nine.vercel.app

Humaniti is a Bangalore-based NPO committed to human and animal welfare — giving impoverished children opportunities, supporting underserved communities, and ensuring every animal has a home.

This website was built and deployed for the organization to establish a public presence, communicate their mission, and facilitate donations. It integrates with Charlie Care via Instamojo for real donation processing.

---

## What It Does

- Presents Humaniti's mission, initiatives, and team
- Connects visitors directly to the donation flow via Instamojo × Charlie Care
- Provides a volunteer/join form for community involvement
- Showcases completed initiatives (government school excursions, animal shelter volunteering, entrepreneurship workshops)

---

## Built With

- HTML, CSS, JavaScript
- Deployed on Vercel

---

## Running Locally

```bash
git clone https://github.com/Sreejay-Reddy/humaniti
cd humaniti
# Open index.html in your browser or use a local server
npx serve .
```
